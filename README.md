# Gerald Pangilinan — Portfolio

Professional personal portfolio for Gerald Pangilinan, focused on systems, operations, ERP/WMS concepts, ecommerce, production workflows, and practical digital product work.

## Stack

- Static HTML, CSS, and JavaScript
- No framework or build dependency
- Responsive dark/light interface
- Accessible keyboard navigation and reduced-motion support
- Self-contained project previews
- Printable web résumé
- Cloudflare Pages-ready

## Cloudflare Pages deployment

Connect this repository to Cloudflare Pages using:

- Production branch: `main`
- Framework preset: `None`
- Build command: leave blank
- Build output directory: `/` or `.`

Every push to `main` can then deploy automatically.

## Main files

- `index.html` — portfolio
- `styles.css` — design system and responsive layout
- `script.js` — theme, menu, reveal, and active navigation behavior
- `resume.html` — printable professional résumé
- `_headers` — Cloudflare response/security headers

## Project identity

This repository lives under the existing GitHub account, but the public website is branded solely as **Gerald Pangilinan**. GDP Clothing is presented as a selected project/case study, not as the identity of the portfolio.
